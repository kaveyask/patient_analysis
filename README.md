# 🏥 Patient Analysis Dashboard | Excel

An interactive **Excel analytics project** analyzing hospital patient data across **Demographics, Medical Conditions, Admissions, Stay Duration, Readmission, Revenue, Insurance, and Patient Outcomes**.

### 📊 Project Overview

* **984** patient records across **29 states**
* **18 attributes** covering patient, clinical, admission, outcome and financial data
* **15 medical conditions** analyzed
* Data period: **January 2022 – February 2026**

### 🛠️ Tools & Skills

**Excel | Pivot Tables | Pivot Charts | Slicers | Data Cleaning | Data Transformation | Data Visualization | Dashboard Design**

### 🔧 Key Work Performed

* **Data Cleaning & Preparation** – removed incomplete records, checked duplicate Patient IDs, standardized text values and corrected data types.
* **Data Transformation** – created age groups, stay-duration bands and year-based analysis.
* **KPI Development** – calculated key metrics including total patients, recovery rate, readmission rate, average satisfaction, revenue and average cost.
* **Pivot Table Analysis** – structured the dataset for interactive cross-filtered analysis.
* **Interactive Dashboarding** – built a consolidated dashboard using slicers, KPI cards and interactive charts.
* **Healthcare Analysis** – analyzed patient demographics, medical conditions, length of stay, readmissions, recovery and satisfaction.
* **Revenue Analysis** – analyzed total revenue and patient volume trends across years.
* **Data Visualization** – used appropriate charts to present healthcare trends and comparisons clearly.
